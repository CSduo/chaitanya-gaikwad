# XIYÀTO — Phase 7: Authority, Agency Directory & Distribution Blueprint

This directory blueprint establishes the legitimate, high-authority third-party platforms where XIYÀTO can build verified business and portfolio profiles. Every platform has been evaluated against commercial buyer relevance, domain authority (DA), backlink quality (dofollow/nofollow), and eligibility criteria.

---

## 1. Distribution Classification Framework

- **Tier A — Extremely Valuable**: High domain authority (DA 70–95+), high enterprise buyer trust, direct procurement referral traffic, verified client review mechanisms, and portfolio publishing support.
- **Tier B — Useful**: Mid-to-high authority (DA 50–70), solid secondary referral channel, active creative and design audience.
- **Tier C — Experimental**: Specialized niche directories, startup hubs, or regional chamber listings with moderate authority (DA 30–50).
- **Reject — Disqualified**: Unmoderated web directories, link networks, automated reciprocal directories, low-quality paid submission sites.
